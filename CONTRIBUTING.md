# Contributing / Mitmachen

🇩🇪 Deutsch weiter unten.

Thanks for your interest! This is a small example project that grew out of a private setup (VW ID.7, evcc, Home Assistant). **There is no support**, but feedback is very welcome.

## Ways to help

- **Tell me what worked or did not** for your car, evcc and Home Assistant version → [Discussions](https://github.com/BrandoCZ/ha-vw-evcc-tracker/discussions). Reports for other VW Group models (Audi, Škoda, Seat, Cupra, …) are especially useful.
- **Report a problem** → [Issues](https://github.com/BrandoCZ/ha-vw-evcc-tracker/issues/new/choose). Please include versions and log lines **without** e-mail addresses, VINs, chat IDs or tokens.
- **Fix a typo, improve a guide, translate a message** → open a pull request. Small, focused changes are easiest to review.

## Pull request notes

- Guides exist in **English and German** (`docs/en`, `docs/de`); please change both or say that the other language still needs an update.
- Entity names start with `vwt_`. In YAML, Home Assistant derives the entity ID from the *name* of template sensors and utility meters, so please do not rename them.
- Do **not** commit personal data: no names, e-mail addresses, VINs, chat IDs, IP addresses, tokens or screenshots with real data.
- If you can, test the packages on a fresh Home Assistant instance and mention what you tested.

# Mitmachen (Deutsch)

Danke für dein Interesse! Das ist ein kleines Beispielprojekt aus einem privaten Setup (VW ID.7, evcc, Home Assistant). **Es gibt keinen Support**, Rückmeldungen sind aber sehr willkommen.

## So kannst du helfen

- **Erzähl, was bei dir funktioniert hat oder nicht** (Auto, evcc- und Home-Assistant-Version) → [Discussions](https://github.com/BrandoCZ/ha-vw-evcc-tracker/discussions). Berichte zu anderen Modellen des VW-Konzerns (Audi, Škoda, Seat, Cupra, …) sind besonders hilfreich.
- **Ein Problem melden** → [Issues](https://github.com/BrandoCZ/ha-vw-evcc-tracker/issues/new/choose). Bitte mit Versionen und Protokollzeilen, aber **ohne** E-Mail-Adressen, FIN, Chat-IDs oder Tokens.
- **Tippfehler korrigieren, eine Anleitung verbessern, eine Meldung übersetzen** → Pull Request. Kleine, klar abgegrenzte Änderungen lassen sich am leichtesten prüfen.

## Hinweise für Pull Requests

- Die Anleitungen gibt es auf **Englisch und Deutsch** (`docs/en`, `docs/de`); bitte beide ändern oder anmerken, dass die andere Sprache noch angepasst werden muss.
- Entitätsnamen beginnen mit `vwt_`. In YAML leitet Home Assistant die Entitäts-ID bei Template-Sensoren und Utility-Metern aus dem *Namen* ab, bitte nicht umbenennen.
- **Keine persönlichen Daten** einchecken: keine Namen, E-Mail-Adressen, FIN, Chat-IDs, IP-Adressen, Tokens oder Screenshots mit echten Daten.
- Wenn möglich, die Pakete auf einer frischen Home-Assistant-Instanz testen und dazuschreiben, was getestet wurde.

## Lizenz

Mit deinem Beitrag stimmst du zu, dass er unter der [MIT-Lizenz](LICENSE) veröffentlicht wird.
